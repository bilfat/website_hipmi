# ARTHAKARSA — Bidang Assets

Empat ilustrasi PNG individual. Seluruh gambar tidak memuat tulisan atau label bidang.

## Isi
- `01-bidang-okk.png` — simbol kaderisasi, organisasi, dan pengembangan anggota
- `02-bidang-eksternal.png` — simbol relasi dan kemitraan strategis
- `03-bidang-medkominfo.png` — simbol publikasi dan media digital
- `04-bidang-ekraf.png` — simbol kewirausahaan dan pengembangan usaha kader

## Spesifikasi
- Format PNG transparan, kanvas 1024 × 1024 px
- Burgundy `#5A1722`, Dark Wine `#3D0F16`, Antique Gold `#E8B577`, Muted Copper `#AF7D66`, Warm Ivory `#FDF7F2`
- Gaya glossy 3D editorial illustration, highlight lembut, pita burgundy-gold

Gunakan `object-fit: contain` / `object-contain`; jangan crop atau recolor. Judul dan deskripsi bidang sebaiknya tetap berupa teks HTML terpisah.
