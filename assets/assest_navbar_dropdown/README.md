# ARTHAKARSA — Menu Illustration Assets

Six standalone transparent PNG illustrations for the HIPMI Universitas Telkom ARTHAKARSA website.

## Asset list
- `01-kabinet.png` — Kabinet
- `02-program-kerja.png` — Program Kerja
- `03-bidang-kompartemen.png` — Bidang & Kompartemen
- `04-bisnis-kader.png` — Bisnis Kader
- `05-agenda-tiket.png` — Agenda & Tiket
- `06-berita.png` — Berita
- `00-overview-six-assets.png` — Original six-asset overview sheet

## Brand palette
- Burgundy: `#5A1722`
- Dark Wine: `#3D0F16`
- Antique Gold: `#E8B577`
- Muted Copper: `#AF7D66`
- Warm Ivory: `#FDF7F2`
- White: `#FFFFFF`

## Usage notes
- Each individual PNG is 1024 × 1024 px with a transparent background.
- Place over a white or warm-ivory UI surface; do not add a new background behind the art unless needed by the component design.
- Recommended display size: 120–220 px for menu cards; maintain a 1:1 aspect ratio.
- Use `object-fit: contain` / `object-contain`; do not crop the illustration itself.
- Keep the palette and scale treatment consistent across all six menu cards.
- Do not bake menu labels into the image; render labels as live website text for responsiveness and accessibility.
